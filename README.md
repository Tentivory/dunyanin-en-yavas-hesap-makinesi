# Dünyanın En Yavaş Hesap Makinesi

Bu repo, modern hayatın hızına isyan eden, her işlemi en az 5 saniye süren efsanevi bir hesap makinesidir. Aceleniz mi var? O zaman niye buradasınız ki?

## Özellikler
- Toplama: 5 saniye
- Çıkarma: 6 saniye
- Çarpma: 7 saniye (matematik zor iş)
- Bölme: 8 saniye (sıfıra bölme daha da uzun sürer, sonsuzluk yavaştır)

## Kurulum
```bash
python yavas_hesap.py
```

Sabır bir erdemdir. Bu makine sizi erdemli yapar.
